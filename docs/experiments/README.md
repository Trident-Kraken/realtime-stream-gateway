# Experiments — raw results

Every artifact in this directory is generated by the reproducible runners
(`tools/run_fault_matrix.sh`, `tools/run_benchmarks.sh`, `tools/replay_trace.sh`)
over the deterministic virtual clock. Re-running with the recorded seed
reproduces each file bit-for-bit (the fault matrix script performs this check
automatically).

- `fault-*.json` / `fault-*.trace` — one file per fault-matrix cell (spec §8.2):
  IID loss {0,1,5,10,20}%, burst loss length {2,4,8} at 20% average, delay,
  jitter, reorder, duplicate, asymmetric paths, control-path loss, and a
  combined "storm" row. Each JSON carries the full parameter set, the
  session ledger, conservation status, latency percentiles, and the
  invariants_ok flag (FDR conservation + zero watchdog violations).
- `bench-comparison.json` — UDP / TCP-model / RUDP-RT / RUDP-RT-always at the
  fixed workload with 5% IID loss, seeds 0x5EED..0x5EED+4.
- `bench-burst.json` — the same arms at 20% average burst-4 loss.
- `bench-fanout.json` — RUDP-RT with three clients (fan-out conservation).

Summary and conclusions: see `results.md`.
