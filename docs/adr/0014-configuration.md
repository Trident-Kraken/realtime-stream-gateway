# ADR-0014: Configuration defaults, validation, and TOML subset

- **Status:** Accepted (Phase 0)
- **Context:** Spec §5 requires configuration validated once before worker creation, invalid cross-constraints failing startup with no silent clamping. The config file format must be dependency-free.
- **Decision:**
  - Files use a strict flat TOML subset: `[section]` headers, `key = value` with integer, decimal float, boolean, quoted string, or duration string (`"100ms"`, `"1s"`, `"500us"`, `"2m"`), `#` comments. No arrays/inline tables; unknown keys are a startup error.
  - Defaults: bind `127.0.0.1:50000`, stream_id 1, SSRC derived from stream, W 64, max_frame_packets 10 (fixed workload), media_payload 1200, D 100 ms, RTO_MIN/MAX 50/1000 ms, playout 60 ms, jitter buffer 64, reorder buffer 256, capture queue 256, control queue 128, metrics snapshots 32, commands 64, timer capacity 4096, turn budget 32 datagrams / 32 KiB, token rate 4 MiB/s burst 64 KiB, control reserve 16 KiB, keepalive silence 200 ms / interval 500 ms / max probes 3, ACK-starvation limit 3×RTO_MAX, max_sessions 16, SO_RCVBUF/SO_SNDBUF request 4 MiB with minimum 256 KiB, drain deadline 1 s.
  - Startup validation (fail closed, no clamping): `1 <= W <= 64`; `1 <= max_frame_packets <= W`; `1 <= media_payload_bytes <= 1200`; `D > 0`; `0 < RTO_MIN <= RTO_MAX`; `playout_delay >= 0`; all queue capacities > 0; `max_sessions >= 1`; `control_reserve_bytes < control_queue_datagrams * 1240`; `token_burst >= 1240`; `token_rate > 0`; keepalive `0 < silence <= interval`; probe counts >= 1; timer capacity >= max_sessions * 8; socket buffers must be granted at or above their configured minimum or startup fails (kernel grant is queried with `getsockopt` after `setsockopt`; a warning is logged when the grant is below the *request* but above the minimum).
  - CLI overrides for address, port, stream, seed, duration, and output paths; every runtime value must trace to validated configuration (no hidden constants; protocol constants like the 28-byte header and 1240-byte datagram cap are part of the frozen wire, not configuration).
- **Consequences:** `config/default.toml` and `config/benchmark.toml` are loadable by gateway, client, sim, and bench; validation errors enumerate every violated constraint.
- **Test anchors:** config validation unit cases (each cross-constraint), unknown-key rejection, duration parsing.
